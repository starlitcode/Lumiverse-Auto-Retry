# Images

Anything the README or the docs pages show. Nothing in here is loaded by the
extension: Lumiverse only ever reads the two files named in `spindle.json`.

`banner.png` is the one the README puts at the top. Replacing it is a matter of
dropping a new file in with the same name, since nothing links to it by any
other path. Keep it wide rather than tall, around 1990 by 790, so it does not
push the first paragraph off the screen on a laptop.
