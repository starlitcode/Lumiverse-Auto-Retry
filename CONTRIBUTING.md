# Contributing

Thank you for wanting to help with Auto Retry.

## Ask first

Before you write any code, tell me about the problem or the idea. Post it or open an issue, as below. That way we can agree on what to change before you spend time on it.

## Bug reports and ideas

Bug reports, ideas and questions are welcome.

- Post them in my [Auto Retry post](https://discord.com/channels/1484149939167821915/1514031700185714688) on the Lumiverse Discord server, or
- [open an issue](https://github.com/starlitcode/Lumiverse-Auto-Retry/issues).

For anything sensitive, such as a security problem, follow [SECURITY.md](SECURITY.md) instead.

## The two branches

- `testing` is where every change goes first, including new and experimental features.
- `stable` is what people install. It only moves when a version is released, so it can be behind `testing`.

## Pull requests

Every change to the code goes through me, so I do not merge pull requests.

- A pull request is still welcome as a way to show a fix or an idea, after you have asked first.
- Start from `testing`, and open the pull request against `testing`, not `stable`. A change made on `stable` can miss work that is only on `testing` so far.
- If I use it, the changelog credits your pull request with a link to it.
- I close the pull request once the change is out.
