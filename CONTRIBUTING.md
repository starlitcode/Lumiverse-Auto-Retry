# Contributing

Thank you for wanting to help with Auto Retry.

## Bug reports and ideas

Bug reports, ideas and questions are welcome.

- Post them under my Auto Retry post on the Lumiverse Discord server, or
- [open an issue](https://github.com/starlitcode/Lumiverse-Auto-Retry/issues).

For anything sensitive, such as a security problem, follow [SECURITY.md](SECURITY.md) instead.

## Pull requests

Every change to the code goes through me, so I do not merge pull requests.

- A pull request is still welcome as a way to show a fix or an idea.
- If I use it, the changelog credits your pull request with a link to it.
- I close the pull request once the change is out.
